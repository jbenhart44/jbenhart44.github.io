What it does

For every picture in a .pptx deck, captioner inserts a short (5–15 word) italic caption directly below the image. The caption identifies what the picture is — so sighted students know at a glance, and so a reviewer has a written record of every visual on every slide.

Each run is non-destructive (the source .pptx is preserved untouched), idempotent (re-runs replace prior captions cleanly), and produces a per-deck audit CSV that records the exact action taken on every shape it encountered.

Capabilities

Every capability below is concrete and enforced by an automated verification gate on each run.

  1. Subject-identifying captions. Each picture gets a short (5–15 word) category-prefixed caption — Photo:, Illustration:, Diagram:, Chart:, Screenshot:, Logo:, Map:, or Icon: — chosen from visual context. Pure subject identification: no descriptive prose, no “image of…” filler.
  2. Vision reads in-image text. When a picture contains typography rendered as part of the image (a warning sign, a screenshot of code, an annotated chart), the caption reproduces the relevant text — not just shapes and colors.
  3. Legible on any background. Each caption sits in a small white card with a light-gray border, so it stays readable on dark section dividers and dark-themed slides where black text would vanish.
  4. Text-aware 2D placement — never covers text. Every text-bearing element (title, subtitle, body, and plain text boxes / auto-shapes) is treated as an obstacle the caption routes around in both dimensions. The occupied text region is measured font- and line-break-aware, so a multi-line or large-font title is correctly avoided rather than under-estimated as a single line.
  5. Captions stay with their picture. Placement prefers directly below the picture; when space is tight it uses a small, unobtrusive band at the picture’s own bottom edge (a thin strip overlapping a sliver of image) rather than letting the caption drift up into the title/body text. Only if even that would cover text is the picture left uncaptioned and flagged for review.
  6. Repeated-background suppression. A full-slide background image that repeats across many slides is detected as template chrome: it is neither captioned (no clutter on every slide) nor treated as a placement obstacle — so the real pictures on those slides still get captioned instead of being blocked by the background.
  7. SmartArt per-icon captioning, no vision pass. PowerPoint stock Icons embedded in a SmartArt store their human-readable name in the SVG id attribute. Captioner reads each name deterministically from the XML and places a short caption directly under the icon — no model call, no variability. Caption size scales to the icon: small icons get small captions (font and box shrink to match) so the caption card never dwarfs the icon it labels.
  8. Decorative & text-only-SmartArt triage. Repeating logos, bullet markers, and slide-master decoration are recorded as [decorative] with no visible caption. SmartArts whose only content is text labels are intentionally skipped — the text already lives in the slide’s accessible text layer.
  9. No overlaps, ever. Two captions never touch, a caption never lands inside a different picture, and nothing intrudes the footer-clearance band (configurable). When no clean position exists, the row is recorded as flagged-no-slot — never forced into a bad spot.
  10. Five-pattern verification gate. Every run is checked by an independent verifier for the five defect classes — text-overlap, footer intrusion, caption-inside-picture, caption-on-caption, and missing captions — in 2D coordinates. It exits non-zero on any defect; intentional skips are recognized as known-skips, not failures.
  11. Audit CSV trail & idempotent re-runs. Every action the tool takes on every shape is logged to a per-deck CSV alongside the output. Caption shapes carry a content-hash name, so re-runs (--update-existing) replace prior captions cleanly — no duplicates accumulate — and hand-edited captions are preserved rather than clobbered.
  12. Configurable & non-destructive. The source .pptx is preserved untouched. A free-text deck context can bias vocabulary; toggles include --no-smartart, --bg-repeat-threshold, and a default-on, whitelist-aware spell-check / date QC pass (--quick / --no-spellcheck / --no-dateqc) that never silently “corrects” a real proper noun.

Scope note. Captioner produces visible compliance-style captions for sighted readers. It does not, on its own, satisfy WCAG 2.1 Success Criterion 1.1.1 — that criterion requires a programmatically determinable text alternative (the OOXML descr attribute consumed by screen readers), which captioner does not write today.

Captioner is best positioned as a pedagogical-clarity layer with an auditable trail, designed to pair with full WCAG alt-text remediation.

What captioner does NOT do

  • Write the OOXML descr alt-text field (the WCAG-canonical attribute consumed by screen readers).
  • Read off chart values — captions identify “this is a chart of X”, not what its data says.
  • Modify embedded charts, the slide master, or any non-Picture shape.
  • Process .ppt legacy format (python-pptx supports .pptx only).

Reliability

Captioner has been run across a large multi-course production set spanning hundreds of pictures and a wide range of slide layouts — title slides, dense bulleted content, photo grids, SmartArt icon strips, full-bleed backgrounds, and dark section dividers. Every delivered deck passes the automated five-pattern verification gate, so a defect (a caption over text, off-slide, inside another picture, or overlapping another caption) cannot ship silently.

Runs are non-destructive — the original .pptx is preserved untouched — and every caption is logged in a per-deck audit CSV for review and editing before sharing.

Install

Prerequisite: Claude Code must be installed — it provides the image-reading (vision) capability the workflow depends on. Captioner runs inside Claude Code, not as a standalone program. You also need Python 3.9+ with python-pptx.

  1. Clone the repository (pinned to v0.2.3).
    git clone https://github.com/jbenhart44/captioner.git
cd captioner
git checkout v0.2.3
  2. Install Python dependencies.
    pip install -r requirements.txt
  3. Run the installer.
    bash install.sh
    This symlinks captioner into your Claude Code skills directory.
  4. Restart Claude Code, then run /captioner <path-to-.pptx-or-folder> to caption a deck.
