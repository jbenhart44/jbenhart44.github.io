Install captioner

Captioner runs inside Claude Code (it provides the image-reading vision). You need Python 3.9+ with git. In your Terminal:

git clone https://github.com/jbenhart44/captioner.git
cd captioner
git checkout v0.3.0
pip install -r requirements.txt
bash install.sh

Then restart Claude Code and run /captioner <path-to-.pptx-or-folder> — add --write-descr to also write alt-text.

Prefer not to use git? Download the v0.3.0 zip from the latest release, unzip it, then run the pip install and bash install.sh steps from inside the folder.
