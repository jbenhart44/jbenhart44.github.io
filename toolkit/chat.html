Use the Tools in a Chatbot

No Claude Code? Some tools also work in an ordinary chat. Open one, copy its prompt into a new chat, and give it your material when it asks. Each prompt starts with a short note that tells the chatbot what it cannot do in a chat, such as run commands or open your files, and never to claim it did.

Made for Claude, works in other chatbots. The tools were written and tested with Claude. You can paste them into ChatGPT, Gemini or Copilot, but nobody has measured the results there, so check the answers the way each prompt asks. If a chatbot asks which Claude account you use, say you are not using Claude Code.

A chat may refuse a long prompt. The /coa, /pace and /quarto prompts are the longest, about 54,000 to 65,000 characters; the others are under 20,000. If it does, open the prompt as text, save it, and attach the file.
